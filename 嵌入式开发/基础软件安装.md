1. 核心语言与代码智能（必装）
C/C++ (Microsoft)

作用：提供代码补全（IntelliSense）、跳转到定义、代码格式化等最基础的功能。

C/C++ Extension Pack (Microsoft)

作用：这是一个大礼包，装了它会自动带上 C/C++ 核心插件以及 CMake 工具链。

2. 构建与项目管理（二选一）
取决于你习惯用哪种方式管理嵌入式工程：

方案 A：CMake Tools (Microsoft) —— 【推荐：适合现代/软硬件结合项目】

作用：如果你的项目（如 STM32、Linux 驱动、ROS 项目）是用 CMake 组织的，这个插件可以实现一键编译、清理和架构选择。

方案 B：Embedded IDE (EIDE) —— 【快捷：适合从 Keil/Cube 迁移的老手】

作用：国人开发的一款神器，能在 Linux 下无缝导入和管理 Keil 或 STM32CubeIDE 工程，内置了各类编译器和烧录器的打包配置，免去了自己写大量 CMakeLists 的烦恼。

3. 硬件仿真与调试（核心）
把代码编译出来只是第一步，能在 Linux 下把程序打进芯片并下断点才是关键：

Cortex-Debug (marus25)

作用：ARM 嵌入式开发的绝对核心插件。 它支持通过 OpenOCD、J-Link、ST-Link 等调试服务器进行硬件在线仿真，支持断点、单步执行、查看变量。
